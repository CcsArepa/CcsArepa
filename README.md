      <h4><a href="https://github.com/CcsArepa/smart-parking-app">Smart Parking UDLAP</a></h4>
      <p>Crowdsourced, real-time parking availability for the UDLAP campus. Students report with a single tap when they park, find a full lot, or leave, and availability updates live for everyone.</p>
      <ul>
        <li>Flutter app for Android, iOS, and the web (installable PWA)</li>
        <li>Clean Architecture with Riverpod 3 and SQLite persistence</li>
        <li>Interface grounded in HCI principles: Fitts's Law, immediate feedback, error prevention</li>
        <li>Interactive campus map and smart suggestions when a lot is full</li>
        <li>Unit, UI flow, and regression tests</li>
      </ul>
